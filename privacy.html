Privacy Notice.

A concise and transparent explanation of technical connection data, client-side preferences, hosting infrastructure, and communications for this portfolio.

Effective: October 31, 2026

1. Overview & Site Purpose

This website is the personal software engineering portfolio of Jose Luis Montejo. Its purpose is to present selected software projects, technical background, and engineering case studies. The site is published as a collection of static files without user accounts, forms, or monetization.

2. Hosting Infrastructure & Technical Connection Data

This portfolio is hosted via Cloudflare Pages (operated by Cloudflare, Inc.). When you request pages, stylesheets, images, or documents from this site, Cloudflare's global edge network automatically processes technical connection data necessary to transmit the files to your device.

This technical data may include your IP address, request URL, referring page, browser user-agent header, and request timestamp. Cloudflare uses this information to deliver web traffic, protect against denial-of-service (DDoS) attacks, detect automated malicious traffic, and maintain edge network security. For further details on Cloudflare's infrastructure handling, see the Cloudflare Privacy Policy ↗.

3. Theme Preferences & Local Storage

The site includes an interactive theme switch (Light/Dark mode) in the navigation header. When you click this toggle, your selected preference ("light" or "dark") is saved directly in your web browser using the localStorage API under the key jose-portfolio-theme.

  • This value is stored exclusively on your local device.
  • It is never transmitted to any external server, remote database, or third-party service.
  • It is used solely to maintain your preferred color scheme across page views and subsequent visits.
  • You can clear this value at any time via your browser's site settings or developer tools.

4. Analytics & Advertising Tracking

This portfolio operates without intentionally enabled analytics platforms or advertising trackers. Specifically:

  • No web analytics tools (such as Google Analytics or Cloudflare Web Analytics) are activated.
  • No advertising networks, retargeting scripts, or conversion pixels are embedded.
  • No behavioral tracking or cross-site user profiling is conducted.

5. Cookies

This site does not set any marketing, profiling, or tracking cookies. Our hosting provider (Cloudflare) may deploy essential security or routing cookies (such as security verification tokens) strictly as required to prevent malicious automated access and ensure reliable infrastructure operation.
